# ANTDRON · Proyecto XP (Metodologías Ágiles · EPN)

Proyecto en dos partes independientes, desarrollado por 6 integrantes con Extreme Programming:

| Parte | Carpeta | Descripción |
|---|---|---|
| 1. Framework XP | `framework-xp/` | Dicta las directrices de XP y verifica que el proyecto las cumpla. |
| 2. Aplicación AntCiberDron | `antdron/` | Lo especificado en el enunciado, dockerizado. Funciona sin el framework. |

**Reparto del trabajo, contratos entre secciones y plan de iteraciones:** [docs/division-tareas.md](docs/division-tareas.md).

Cada integrante sube su sección por pull request. El Integrante 1 abre el proyecto con la estructura de ambas partes y la guía de directrices (iteración 0).
